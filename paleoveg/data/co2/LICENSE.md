# Data license and attribution

The atmospheric CO₂ observations in this directory are derived from the CEDA
IPCC AR6 Figure 2.4 dataset and remain licensed under the
[Creative Commons Attribution 4.0 International license](https://creativecommons.org/licenses/by/4.0/).
This data license is separate from PaleoVeg's MIT software license.

When publishing results that use this lookup, cite the Ahn (2023) dataset,
the IPCC AR6 Working Group I Chapter 2 report component, and the related CO₂
source publications requested in the
[CEDA catalogue record](https://catalogue.ceda.ac.uk/uuid/60eeb3cce51a457cb5ee1c577a0c8674/).

The PaleoVeg transformation is limited to extracting the age and CO₂ columns
and adding an age axis relative to 1950. Values are interpolated only at runtime.
